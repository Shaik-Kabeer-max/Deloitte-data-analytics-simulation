# 📊 Deloitte Data Analytics Job Simulation

This repository contains the projects completed as part of the Deloitte Data Analytics Virtual Experience. The tasks focused on data visualization and logical data transformation.

---

## 📂 Project Structure

### 1️⃣ 📈 Telemetry Data Dashboard (Tableau)
**🎯 Objective:**  
Analyze device telemetry data to identify "unhealthy" machinery across different factories.

**🔑 Key Work:**
- Cleaned and processed a dataset of **160,000+ rows**
- Created a dashboard comparing:
  - Factory-wise unhealthy devices 🏭  
  - Device type analysis ⚙️  
- Identified trends to support maintenance decisions 📊  

**🛠️ Tools:** Tableau Public  


---

### 2️⃣ 💰 Compensation Equality Analysis (Excel)
**🎯 Objective:**  
Classify employee equality scores to identify pay disparities.

**🔑 Key Work:**
- Added a new column: `Equality Class`
- Used Excel formulas (`IF`, `ABS`) for classification
- Categorized scores into:
  - ✅ Fair: -10 to +10  
  - ⚠️ Unfair: ±10 to ±20  
  - ❌ Highly Discriminative: > ±20  

**🛠️ Tools:** Microsoft Excel
